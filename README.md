# AUTOFIELD

Autofield is an experimental robotics autonomous field simulation designed to help robotics teams and developers test, develop, and evaluate robot movement without requiring a physical robot or competition field. It provides a virtual environment for simulating robot movement, physics, and interactions, making it easier to prototype autonomous routines and test motion-control algorithms.

The project aims to provide a flexible simulation platform that can be integrated with existing robotics libraries and team-developed software. By replicating aspects of real-world robot behaviour, Autofield can help developers identify issues, refine movement strategies, and improve autonomous performance before deploying code onto physical robots.

Progress

- [x] Physics Collision — Collision detection and physical interactions between objects.
- [x] Gamepad Control — Manual robot control using a connected gamepad.
- [ ] Dynamic Fields — Dynamically configurable field environments.
- [ ] Drift Physics — Simulating momentum, wheel slippage, and drift during movement.
- [ ] Roboscope Compatibility — Integration with the Roboscope simulation ecosystem.
